2D scope: signal "D0"

This example shows CircuitJS1.watchSignal()/onsignalupdate - the replacement for driving a scope-like display from JS. Instead of a per-timestep callback (which the digital fast-path simulator can't cheaply provide - a "sleeping" chip skips real ticks entirely), the simulator calls onsignalupdate once per draw with, for every watched signal, only the (tick, value) transitions that actually happened since the last call - exactly the change-list a real Scope reads from Chip.history. This page folds those changes into a small raster-style 2D plot drawn directly onto a <canvas> in the sidebar, the same way ScopePlot2d.ts paints a raster inside the simulator itself.
